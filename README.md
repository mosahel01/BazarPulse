# MarketPulse

A stock-community platform: stock discussion, trading ideas, watchlists, voting, moderation, and a prediction game. Backend-first with a functional frontend. Not financial advice — market prices are generated by the built-in market-data engine, not real markets.

## Stack

Node.js · TypeScript · Fastify · SQLite + Drizzle · JWT auth · Google Sign-In · Zod · Vitest · Python (optional market-data worker)

## Quick start

```bash
npm install
cp .env.example .env    # set AUTH_SECRET (openssl rand -hex 32)
npm run dev             # http://localhost:3000
```

Migrations apply automatically at boot. `npm run db:seed` loads optional demo data (seeded users share password `MarketPulse@2026`).

The market engine generates deterministic per-day quotes and indices. It runs an in-process TypeScript simulator by default and, when Python 3 is available and `MARKET_ENGINE=auto` (the default) or `MARKET_ENGINE=python`, launches the Python worker and falls back to the simulator if it fails. Set `MARKET_ENGINE=ts` to force the simulator.

The frontend uses the real REST API when it can, and falls back to local demo data when the backend is unreachable.

## Production

```bash
npm run build && npm start
```
